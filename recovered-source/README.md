# LHSMENU recovered source

This directory contains Java source reconstructed from the distributed
LHSMENU.jar using the CFR Java decompiler, plus the non-class resources
extracted from that same JAR.

Modules present in the binary:
- mainlhs — 1.5.0
- lhs_auth — 1.1.0
- lhs_lobby — 1.1.0

These are decompiled sources, not the original developer-authored source.
Names and comments may be missing, and some Minecraft/Forge calls may
retain remapped names. A matching Forge 1.20.1 development environment
and dependency setup may be needed before the sources can be rebuilt.

Original binary: repository root, LHSMENU.jar.
